# Memes Arcade - Desktop app

The website's **Download** tab offers two builds. They run the same window; the
difference is whether the game server travels with you.

| | 🪶 Desktop Lite | 🏠 Desktop Host |
|---|---|---|
| Download | ~10 KB + one-time Electron install | ~400 KB (the whole arcade) |
| Server included | no | yes - server, website, engines, music |
| Needs internet | yes, to reach a website | no - runs on your machine |
| Host your own matches | no | yes, including LAN parties |
| Connect to the online arcade | yes | yes (Server menu) |
| Account, friends, settings | same everywhere | same everywhere |

Both packages are generated by the running server
(`server/lib/downloads.js` + `server/lib/zip.js`), so a download always matches
the build you are looking at. Nothing is written to disk on the host: archives
are built in memory and cached for a few minutes.

## Lite

1. Install Node.js 18+.
2. Unzip, then run `run-windows.bat` (Windows) or `bash run-mac-linux.sh`.
   The first run installs Electron once (~90 MB).
3. Pick **Connect to a website**, confirm the address (the one you downloaded
   from is pre-filled), and sign in.

`config.default.json` in the archive bakes in the default server, so a shared
Lite build opens straight onto your arcade.

## Host

Unzip anywhere and either:

```bash
npm start                      # server + website on http://localhost:8787
cd desktop && npm install && npm start   # the desktop window instead
```

The server has **zero dependencies** - `npm start` works immediately, no
`npm install` required. Node 18+ is the only prerequisite.

**Host mode** in the desktop app starts that same server as a child process,
waits for `/api/health` to answer, then loads it. Your saves live in Electron's
`userData` folder (Server → *Open the folder with my saves*), so updating the
app never wipes accounts.

## Modes

| Mode | What it does |
|---|---|
| **Host** | Starts the bundled server, plays fully offline. Friends on your wifi join via the "Same wifi" address printed at boot. |
| **Lite** | Points the window at any arcade URL. Nothing runs locally. |
| **Auto** | Host builds default to Host; Lite builds default to Lite. |

Switch any time from the **Server** menu:

- *Connect to a website…* - back to the launcher to type a new address
- *Start local server (host mode)* - play offline (Host build only)
- *Stop local server*
- *Copy invite link*

## How the launcher talks to Electron

`preload.js` exposes exactly one object, `window.arcade`, with `info`,
`connect`, `startHost`, `stopHost`, `saveSettings`, `openExternal`,
`openFolder`, `onStatus` and `onServerStopped`. The renderer has no Node
access: `contextIsolation` is on, `nodeIntegration` is off, and the launcher
page runs under a strict Content-Security-Policy.

## Notes

- The website detects the desktop shell (`window.arcade`) and shows
  desktop-specific guidance on the Download page.
- A second launch focuses the existing window instead of opening another one.
- The bundled server binds `127.0.0.1` by default in host mode. Set
  `MEMES_HOST=0.0.0.0` if you want the whole network to reach it.
- Port conflicts: change the port in `desktop-settings.json`
  (Server → *Open the folder with my saves*) or set `MEMES_PORT`.

## Troubleshooting

| Symptom | Fix |
|---|---|
| "The local server did not come up" | Node 18+ not installed, or the port is taken. Try `npm start` in a terminal to see the real error. |
| Blank window on connect | The address answered no `/api/health`; the app still navigates. Check the URL includes `https://` for hosted servers. |
| Electron download fails | Corporate proxy? Run `npm install` inside `desktop/` manually once. |
| Want a real installer (.exe/.dmg) | `npx electron-builder` in `desktop/` - not shipped by default to keep the download tiny. |
